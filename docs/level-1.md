# 1단계 · 누구나

컴퓨터나 과학을 따로 배운 적이 없어도 읽을 수 있는 글이에요. 덧셈과 뺄셈만 알면 따라올 수 있게 썼고 어려운 낱말은 처음 나올 때 풀어 썼어요.

| 갈래 | 다루는 것 |
|---|---|
| [컴퓨터](computer/index.md) | 컴퓨터가 사진·글자·숫자를 어떻게 기억하고 일하는지 |
| [인체](body/index.md) | 우리 몸에 있는 것들이 왜 있는지 |
| [물질과 에너지](matter/index.md) | 물·불·빛·전기가 왜 그렇게 되는지 |

세 갈래는 어느 것부터 읽어도 괜찮아요. 컴퓨터 갈래를 다 읽었다면 [2단계](level-2.md)로 넘어갈 수 있어요.
