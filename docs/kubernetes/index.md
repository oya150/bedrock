# 쿠버네티스

요즘 서버 프로그램은 대부분 컨테이너에 담겨 쿠버네티스 위에서 돌아가요. 그러다 보면 "왜 이렇게 동작하지?"에서 막히는 때가 와요. 설정 한 줄 바꿨는데 파드가 전부 다시 뜨거나 컨테이너 안 프로그램이 붙인 디스크에 쓰지 못하는 일이 생겨요. 디스크 사진(스냅샷)은 눈 깜짝할 새 찍히는데 프로그램은 한참 걸려서 뜨기도 해요.

이 갈래는 이런 일의 바닥에 있는 원리를 따라가요. 컨테이너가 무엇인지에서 시작해 컨테이너를 서로 떼어 놓는 방법을 봐요. 그다음 쿠버네티스가 일하는 방식과 CPU·메모리 몫을 보고 데이터를 담는 디스크와 프로그램을 빨리 띄우는 방법을 지나 비밀값과 권한으로 끝나요. 예시는 처음부터 끝까지 동네 빵집의 주문 앱 하나로 이어 가요.
