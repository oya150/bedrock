# 쿠버네티스

요즘 서버 프로그램은 대부분 컨테이너에 담겨 쿠버네티스 위에서 돌아가요. 그러다 보면 "왜 이렇게 동작하지?"에서 막히는 때가 와요. 설정 한 줄 바꿨는데 파드가 전부 다시 뜨고, 컨테이너 안에서 만든 파일을 밖에서 못 열고, 디스크 사진(스냅샷)은 눈 깜짝할 새 찍히는데 프로그램은 한참 걸려서 떠요.

이 갈래는 이런 일의 바닥에 있는 원리를 따라가요. 컨테이너가 무엇인지에서 시작해서, 컨테이너를 서로 떼어 놓는 방법, 쿠버네티스가 일하는 방식, 데이터를 담는 디스크, 프로그램을 빨리 띄우는 방법, 권한과 비밀값 순서로 내려가요. 예시는 처음부터 끝까지 동네 빵집의 주문 앱 하나로 이어 가요.

서버를 다뤄 본 적 없는 분도 따라올 수 있게 썼어요. 본문 중간의 "심화" 칸은 더 깊이 알고 싶은 분을 위한 이야기라서 닫아 둔 채 읽어도 괜찮아요.
