# 인체

숨 쉬기, 밥 먹기, 다친 곳이 아무는 일처럼 늘 겪는 일에서 출발해 몸속에서 무슨 일이 일어나는지 알아봐요. 이름을 외우기보다 까닭을 알아봐요.

| 편 | 주제 | 읽고 나면 알게 되는 것 |
|---|---|---|
| 1 | [세포: 몸을 이루는 작은 방](01-cells.md) | 몸은 작은 방인 세포로 되어 있고 세포는 영양과 산소로 힘을 만들고 둘로 나뉘어 상처를 메워요. |
| 2 | [숨: 산소가 들어오고 다 쓴 숨이 나가는 길](02-breathing.md) | 공기는 폐 속 작은 주머니까지 가서 산소와 다 쓴 숨이 오가고 다 쓴 숨이 쌓이면 뇌가 숨을 쉬게 해요. |
| 3 | [소화: 밥 한 숟가락이 몸속에서 가는 길](03-digestion.md) | 밥은 입에서 큰창자까지 지나며 세포가 받을 만큼 쪼개지고 작은창자 돌기로 피에 들어가요. |
| 4 | [피: 산소와 영양을 온몸에 나르는 길](04-blood.md) | 피는 심장에서 나가 실핏줄의 얇은 벽으로 세포와 주고받고 돌면서 폐와 작은창자에서 다시 실어요. |
| 5 | [심장: 쉬지 않고 피를 짜서 미는 근육 주머니](05-heart.md) | 심장은 짜고 풀기와 한쪽으로만 열리는 문으로 피를 한 방향으로 밀고 스스로 박자를 만들어요. |
| 6 | [피가 멈추는 과정: 혈소판 마개에서 딱지까지](06-clotting.md) | 다친 핏줄은 오므라들고 혈소판이 마개를 만들고 실 그물이 굳혀 딱지가 돼요. |
| 7 | [땀: 몸이 열을 식히는 방법](07-sweat.md) | 뇌가 체온을 지키려고 핏줄을 넓히고 땀을 내요. 땀은 피부 위에서 마를 때 열을 가져가요. |
| 8 | [손톱과 머리카락: 잘라도 아프지 않은 까닭](08-nails-hair.md) | 눈에 보이는 손톱과 머리카락은 신경이 없는 굳은 세포라 잘라도 아프지 않아요. |
| 9 | [뼈와 근육: 팔을 굽히고 펴는 방법](09-bones-muscles.md) | 근육은 당기기만 해서 짝을 이루고 관절 가까이를 조금 당겨 팔을 크게 움직여요. |
| 10 | [눈이 보는 방법: 빛에서 뇌까지](10-eyes.md) | 빛은 눈동자와 렌즈를 지나 망막에 모이고 보는 일은 뇌가 해요. |
| 11 | [뇌와 척수: 알림을 받아 몸에 명령하는 길](11-brain.md) | 알림은 척수를 타고 뇌로 가고 명령은 근육으로 나가요. 뜨거운 것에 닿으면 척수가 먼저 명령을 돌려보내요. |
| 12 | [면역: 몸이 감기를 막고 물리치는 방법](12-immune.md) | 피부와 콧물이 먼저 막고 넘어온 침입자는 흰 세포가 삼키고 한 번 만난 침입자는 기억해요. |
