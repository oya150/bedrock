# Elasticsearch

Elasticsearch(이하 ES)를 쓰다 보면 "왜 이렇게 동작하지?"에서 막히는 때가 와요. 저장했는데 바로 안 보이고, 같은 검색어인데 환경마다 순위가 다르고, 샤드 수는 나중에 바꿀 수 없어요. 이런 일의 답은 대부분 ES 안의 자료구조와 알고리즘에 있어요.

이 갈래는 문서 한 건이 ES에 들어와서 검색되어 나가기까지를 따라가면서 그 바닥까지 내려가요. ES를 막 쓰기 시작한 개발자를 생각하고 썼어요. 본문 중간의 "동료용 심화" 칸은 ES를 오래 운영한 분을 위한 구현 이야기라서 닫아 둔 채 읽어도 괜찮아요.

본문은 ES 7부터 9까지 똑같이 맞는 내용만 담았어요. 버전마다 다른 기본값이나 파일 형식은 심화 칸에 버전을 붙여 적었어요. 편마다 로컬 도커 ES로 직접 해 보는 명령이 있어요.
