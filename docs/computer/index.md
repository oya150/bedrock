# 컴퓨터

컴퓨터가 어떻게 일하는지 바닥부터 그림으로 봐요. 알고리즘을 읽기 전에 먼저 보면 좋아요.

| 편 | 주제 | 읽고 나면 알게 되는 것 |
|---|---|---|
| 1 | [컴퓨터가 하는 일: 더하기, 비교, 바꿔 적기](01-what-computers-do.md) | 컴퓨터는 더하기·비교·바꿔 적기 같은 쉬운 일을 사람이 적어 둔 명령어대로 아주 빨리 해요. |
| 2 | [사진을 숫자로 기억하기: 픽셀과 색 번호](02-how-computers-keep-pictures.md) | 사진은 픽셀이라는 작은 칸으로 되어 있고 컴퓨터는 칸마다 색 번호를 적어 기억해요. |
| 3 | [글자 번호표: 컴퓨터가 글자를 기억하고 보내는 방법](03-how-computers-keep-letters.md) | 컴퓨터는 글자마다 정한 번호를 기억하고 보내요. 받는 쪽도 같은 표로 읽어야 글자가 제대로 떠요. |
| 4 | [비트: 켜짐과 꺼짐으로 숫자를 적는 방법](04-what-numbers-look-like.md) | 켜짐과 꺼짐 칸에 두 배씩 커지는 점을 붙여 더하면 큰 수를 적어요. |
| 5 | [메모리와 저장 장치: 컴퓨터가 숫자를 적어 두는 두 곳](05-where-computers-remember.md) | 지금 쓰는 숫자는 끄면 지워지는 메모리에, 오래 둘 숫자는 꺼도 남는 저장 장치에 적어요. |
| 6 | [코드와 반복: 쪽지 한 장으로 백 칸 가기](06-how-to-tell-computers.md) | 명령어를 차례로 적은 게 코드이고 같은 명령어는 "몇 번 반복"으로 한 번만 적어요. |
| 7 | [버그와 디버깅: 컴퓨터가 엉뚱하게 움직일 때](07-can-computers-be-wrong.md) | 컴퓨터는 쪽지에 적힌 대로만 움직여서 쪽지 속 잘못도 따라 해요. 쪽지를 따라 세면 찾아 고칠 수 있어요. |
| 8 | [프레임: 영상이 움직여 보이는 까닭](08-how-videos-move.md) | 영상은 조금씩 다른 사진을 1초에 30장씩 바꿔 보여 줘서 움직여 보여요. |
| 9 | [화면 터치: 누른 자리를 컴퓨터가 알아내는 법](09-how-touch-works.md) | 화면 속 가는 줄로 손가락 자리를 숫자 두 개(좌표)로 알아내고 버튼 칸 안인지 보고 할 일을 정해요. |
| 10 | [암호와 열쇠: 남이 못 읽게 메시지를 바꾸는 법](10-how-to-keep-messages-secret.md) | 글자를 열쇠만큼 밀어 쓰면 암호가 되고 아주 긴 열쇠를 쓰면 하나씩 넣어 봐도 못 풀어요. |
| 11 | [메시지가 가는 길: 인터넷과 서버](11-how-messages-travel.md) | 메시지는 주소만 보고 넘기는 중간 컴퓨터들을 거쳐 가고 친구 휴대폰이 꺼져 있으면 서버가 맡아 둬요. |
| 12 | [검색과 색인: 쌓인 메시지에서 낱말 찾기](12-how-search-works.md) | 휴대폰은 메시지가 올 때마다 낱말별 번호표(색인)를 적어 두고 검색할 때 그 줄만 찾아요. |

1편부터 6편까지는 컴퓨터의 바닥이에요. 7편부터는 그 바닥 위에서 컴퓨터가 일하는 모습을 봐요.
