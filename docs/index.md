# bedrock

프로그램을 만드는 사람들 사이에는 "원래 그래" 하고 넘어가는 말이 있어요. "빅오는 앞의 숫자를 버린다", "dict는 빠르다" 같은 것들이요. 여기서는 그런 말 하나를 골라 왜 그런지 직접 재 보고 세어 봐요.

어디까지 파고들지는 "그래서 고쳐야 해, 말아야 해?"에 혼자 답할 수 있는 데까지로 정했어요. 프로그램을 몰라도 따라올 수 있게 그림과 표를 많이 넣었고, 수식이나 역사는 궁금한 분만 펼쳐 보게 접어 뒀어요.

편마다 질문 하나를 다루고 끝에 판단해 볼 문제를 붙였어요. 숫자는 다 직접 잰 거라, 잰 코드도 같이 올려 뒀어요.
