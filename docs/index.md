# bedrock

개발하다 보면 원래 그렇다며 넘어가는 문장이 있다. 빅오는 상수를 버린다, dict는 빠르다 같은 것들이다. 여기서는 그런 문장 하나를 골라 왜 그런지 실제로 재 보고 세어 본다.

어디까지 팔지는 실무에서 "그래서 고쳐야 하나?"에 답할 수 있는 데까지로 정했다. 그래야 "우리 데이터는 늘 30개인데 빅오를 따질 필요가 있나" 같은 질문에 혼자 답할 수 있다.

편마다 질문 하나씩 다루고, 끝에는 서비스를 만들다 만날 법한 판단 문제를 붙였다. 코드는 파이썬으로 쓰고, 문서에 실린 측정값은 직접 돌려 볼 수 있게 스크립트를 함께 둔다.
