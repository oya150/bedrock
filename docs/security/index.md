# 보안

로그인하면 왜 한동안 비밀번호를 다시 묻지 않을까요? 남이 내 출입증을 고쳐 쓰지 못하게 막는 건 무엇일까요? 이 갈래는 서비스가 사람을 알아보고 지키는 원리를 작은 숫자 예시로 하나씩 따라가요.

먼저 [컴퓨터 10편](../computer/10-how-to-keep-messages-secret.md)에서 암호와 열쇠를 보고 오면 좋아요. 거기서는 두 사람이 같은 열쇠를 나눠 가졌는데 서명에서는 열쇠가 둘로 갈라져요.

| 편 | 주제 | 읽고 나면 알게 되는 것 |
|---|---|---|
| 1 | [디지털 서명: 고쳐 쓴 로그인 토큰이 들키는 까닭](01-signature.md) | 서명은 요약 숫자를 개인키로 계산한 값이라 한 글자만 고쳐도 걸려요. 개인키가 새면 열쇠를 바꿔야 해요. |
